Track 3 — Challenge Specifications

ResolveFlow delivers an autonomous AI agent for end-to-end customer support that goes beyond conversational chatbots to perform true ReAct reasoning, stateful database mutations, and failure replanning.

Evaluation Criteria Exceeded:
  • Visibly Defined ReAct Loop: Step-by-step goal formulation, tool calls, observations, actions, replanning, verification, and outcomes.
  • Dynamic Replanning on Failure: Intercepts out-of-stock (Stock: 0) failure from create_replacement(), revises strategy, evaluates fallback policies, and executes secondary remedy (100% refund + courtesy credit).
  • Safety & Policy Enforcement: Safely escalates policy violations (e.g., 95 days post-delivery) to human supervisor without unapproved financial dispatch.
  • Independent Cryptographic Verification: Queries SQLite relational tables post-execution and stamps a SHA-256 audit digest.
